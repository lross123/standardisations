![Status](https://img.shields.io/badge/Status-Active-success?style=for-the-badge) ![Version](https://img.shields.io/badge/Version-1.0.0-blue?style=for-the-badge) ![Engineering](https://img.shields.io/badge/Focus-Engineering_Efficiency-orange?style=for-the-badge)

> **Streamlining Engineering Precision**  
> A centralised tool designed to enhance workflow efficiencies by providing instant, accurate, and standardised metric conversions for the engineering team.

## 🚀 Overview

The **Metric Conversion Dashboard** is a simple interface for engineering teams to rapidly convert between Imperial and Metric units. Eliminating the need for ad-hoc calculations, this dashboard ensures consistency across project documentation and technical specifications.

Designed with a **focus on workflow efficiency**, the interface enables quick data entry and real-time computation, allowing engineers to focus on design and analysis rather than unit arithmetic.

## 🛠 Features

This dashboard includes comprehensive conversion modules tailored for engineering applications:

| Module | Icon | Supported Units |
| :--- | :---: | :--- |
| **Length** | 📏 | mm, cm, m, km, in, ft |
| **Area** | ⬜ | mm², m², ft² |
| **Volume** | 💧 | ml, L, cm³, m³, ft³, gal (US/UK) |
| **Mass** | ⚖️ | g, kg, tonnes, oz, lbs |
| **Force** | 💪 | N, kN, lbf |
| **Pressure** | 🔽 | Pa, kPa, bar, psi, atm |
| **Energy** | ⚡ | J, kJ, kWh, BTU |
| **Power** | 🔌 | W, kW, hp |
| **Speed** | 🚀 | m/s, km/h, mph |
